# Tools 工具集

一个轻量的网页工具集合,全部由纯 HTML + CSS + JavaScript 编写。下载后直接用浏览器打开即可使用,无需安装依赖、无需联网。

## 包含工具

### 32 位位选择器 × 6(`bit-to-hex-x6.html`)

一页内提供 6 个相互独立的 32 位数值编辑器。逐个点击位按钮切换 0 / 1,实时查看对应的十六进制(HEX)及十进制数值,适合用来拼装寄存器值、掩码或配置字。

功能:

- 32 位二进制逐位开关,顶部带位号(31 → 0),悬停可查看权重
- 实时显示 HEX、无符号十进制、int32 有符号十进制、二进制
- 6 个计算器完全独立,各自支持:清零、全 1、随机、输入 HEX 载入、一键复制
- 每个计算器可填写简短注释,自动保存到浏览器本地(localStorage),刷新不丢失
- 自适应布局铺满屏幕:宽屏(≥1400px)3 列 × 2 行,中屏 2 列 × 3 行,手机单列,每卡内位按钮自动折成两排
- 自动适配浅色 / 深色系统主题

## 使用方法

1. 克隆或下载本仓库;
2. 用 Chrome / Edge / Firefox 等浏览器直接打开 HTML 文件;
3. 不需要服务器,也不需要安装任何依赖。

## 技术说明

- 纯原生 HTML / CSS / JavaScript,零第三方依赖
- 数值按 32 位无符号整数计算;当 bit 31 置位时,`int32` 一栏显示补码形式的负数
- 注释内容通过 `localStorage` 保存在当前浏览器中,仅本机可见
