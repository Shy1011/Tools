毛刺清理(不改原始数据)
处理方法
· 毛刺清理(中值滤波):y′[i] = median(y[i-k] … y[i+k]),窗口 N 取 3–21 的奇数,k=(N−1)/2;首尾用镜像点补齐。
· 叠加滑动平均:y″[i] = (y′[i-k] + … + y′[i+k]) / m,m 是窗口内实际参与平均的点数;首尾只平均实际存在的点。
· 处理顺序:隐藏点/补线 → 中值滤波 → 滑动平均 → 绘图。X 值不变,也不做降采样。
· “平滑曲线”只改变连线外观;滑动平均会改变显示层 Y 值。原始 CSV 不变,勾选“导出处理结果”后 CSV 才使用处理值。
处理只影响显示,原始数据(文本框、默认导出 CSV)保持不变;取消勾选即可对比原始曲线。橡皮擦改为「隐藏」数据点,隐藏段自动用平滑曲线补上(可关闭「擦除后平滑补线」),可撤销/重做。勾选「导出处理结果」后,导出 CSV 与图像完全一致(含补线点)。
按值标记
在所选曲线上找 X 或 Y 最接近输入值的数据点并添加/取消标记;输入框内按回车也可触发。
测量光标
开启后在绘图区出现两条虚线光标,直接拖动即可测量两点间差值;读数框默认在绘图区左上角,可按住拖动调整位置,并带有 ΔX / ΔY 箭头标记。X / Y 可单独或同时开启。
区间统计与拟合
普通拖动仍缩放;按住 Shift 在绘图区拖动可选择 X 统计区间。

操作说明
· 鼠标拖拽框选区域可放大
· 双击画布恢复自动范围
· 按住空格键拖动画布可平移
· 鼠标悬停数据点显示精确坐标
· 单击数据点可添加/取消标记,支持同时标记多个点
· 勾选「测量光标」中的 X / Y 光标,拖动虚线即可测量两点间 ΔX / ΔY,可同时开启
· 光标读数框可拖动;重置视图(双击或按钮)只重置缩放,不会删除标记与光标
· 「区间统计与拟合」可手动或用当前视图设定 X 范围;Shift+拖动只选统计区间,普通拖动仍缩放
· 工具栏「导出文件名」留空时使用图表标题;填写后严格使用该文本作为文件名(自动补 .png/.csv/.xlsx)
· 可输入 X / Y 值在指定曲线上精确定位标记点
· 拖动标题 / X 轴名称 / Y 轴名称可调整位置
· 拖动标记点旁边的坐标文字可调整位置,移开后显示指引箭头
· 每条曲线可设置线条粗细(线宽)
· 「毛刺清理」为显示层处理:中值滤波去毛刺,可调窗口/叠加滑动平均,不改原始数据
· 工具栏「橡皮擦」:开启后拖动框选或单击可隐藏数据点,隐藏段自动用平滑曲线补上,原始数据不变,可撤销/重做
· 刻度方式:自动漂亮数 / 等分 / 固定步长 / 数据点 / 自定义
· 标题、标签样式、曲线数据都会自动保存在本浏览器,刷新不丢失
· 导出 CSV 为英文表头的宽表格式;导出 Excel 时包含「曲线数据」「说明」「图表」三个 Sheet,图表内嵌当前 PNG 图;导出的 XLSX 可直接载入并恢复完整绘图状态
· Log 坐标会自动跳过 0 和负数
· Log 坐标范围较小时会自动细分刻度并标注(如 0.1–0.7 会标出 0.1、0.2、…、0.7)
